# Maintainer Communication

## Ask For Help Without Outsourcing Thinking

Good question shape:

- what you tried
- what you expected
- what happened
- the smallest anchored code path you traced
- one hypothesis you already considered

Templates:

- Bug report: symptom, reproduction, expected, actual, evidence anchors, command results
- Feature proposal: user value, existing pattern to follow, likely files, risks
- Review response: what you changed, what you disagree with, what evidence you used
