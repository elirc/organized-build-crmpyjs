# Learning Rubrics

## Junior

- Can run the project using documented commands.
- Can name backend vs frontend responsibilities.
- Can trace login end to end with file anchors.
- Can make a safe UI-only or test-only change and re-run checks.

## Mid-Level

- Can add a small backend route using current patterns.
- Can explain validation, auth, and persistence boundaries separately.
- Can write at least one negative test.
- Can identify one architectural risk and propose a low-blast-radius fix.

## Senior

- Can critique current tradeoffs without overclaiming.
- Can propose migrations, rollback, and test strategy together.
- Can distinguish confirmed issues from hypotheses.
- Can teach the same concept in repo-specific and transferable terms.

## Self-Assessment Checklist

- I can tell where business logic belongs in this repo.
- I can explain why client auth gating is not server security.
- I can identify where a schema change would ripple.
- I can write a PR description with risks and follow-ups.
